# 画像変換ツール (gazouhenkan)

WebブラウザでかんたんにできるシンプルなAI画像変換Webアプリ。  
**WebP→JPEG変換**・**AI背景除去**・**SVGベクター化** の3機能をノーインストールで利用できる。

---

## 機能一覧

| 機能 | 説明 | 出力形式 |
|------|------|---------|
| WebP → JPEG | WebP画像を高品質JPEGに変換 | `.jpg` |
| 背景透明化 | AIが自動で背景を除去（透過PNG生成） | `.png` |
| ベクター化 | ラスター画像をSVGベクターに変換（カラー/白黒） | `.svg` |

---

## 起動方法

### 方法 1 — ローカル（Python直接実行）

**前提**: Python 3.12 がインストール済みであること

```bash
# 依存ライブラリのインストール
pip install -r requirements.txt

# 開発サーバー起動
python app.py
```

ブラウザで http://localhost:5000 を開く。

---

### 方法 2 — Docker

```bash
# イメージのビルド
docker build -t gazouhenkan .

# コンテナの起動
docker run -p 10000:10000 gazouhenkan
```

ブラウザで http://localhost:10000 を開く。

---

### 方法 3 — Render.com（クラウドデプロイ）

1. このリポジトリを GitHub にプッシュ
2. [Render.com](https://render.com) で **New Web Service** を作成
3. リポジトリを連携すると `render.yaml` が自動検出され、設定が適用される
4. デプロイ完了後、発行された URL にアクセス

> ヘルスチェックは `/healthz` エンドポイントで行われる。

## 操作方法・使い方

### 共通手順

1. 画面上部のタブで機能を切り替える
2. 「ファイルを選択」から画像をアップロード
3. 右パネルにプレビューが表示される
4. 変換ボタンをクリック → 処理完了後、ファイルが自動ダウンロードされる

---

### WebP → JPEG 変換

1. タブ「**WebP → JPEG**」を選択
2. `.webp` ファイルを選択
3. **「変換してダウンロード」** をクリック
4. `{ファイル名}_{日時}.jpg` でダウンロードされる

**品質**: JPEG 品質 95%（高品質）

---

### 背景透明化

1. タブ「**背景を透明化**」を選択
2. 画像ファイル（JPG / PNG / WebP など）を選択
3. **「背景を除去してダウンロード」** をクリック
4. `{ファイル名}_nobg_{日時}.png` でダウンロードされる

> 初回実行時はAIモデルのダウンロードが発生するため、処理に時間がかかる場合がある。

---

### ベクター化（SVG変換）

1. タブ「**ベクター化**」を選択
2. JPG または PNG ファイルを選択
3. モードを選択：
   - **カラー**: フルカラーでSVGを生成
   - **白黒**: 白黒のSVGを生成
4. 必要に応じてパラメータを調整（詳細は下表）
5. **「変換してSVGをダウンロード」** をクリック
6. `{ファイル名}_{色数}colors_{日時}.svg` でダウンロードされる

#### ベクター化パラメータ詳細

| パラメータ | 範囲 | デフォルト | 説明 |
|-----------|------|-----------|------|
| 色数 (colors) | 2 〜 256 | 16 | 使用する色の数（カラーモードのみ）|
| フィルタースペクル (filter_speckle) | 1 〜 100 | 4 | 小さなノイズを除去する強度。大きいほど細かい点が消える |
| コーナー閾値 (corner_threshold) | 1 〜 180° | 60 | 角の判定基準。小さいほど角が多く検出される |
| 最短パス長 (length_threshold) | 1.0 〜 10.0 | 4.0 | これ以下の短いパスは無視される。大きいほど細部が省略される |
| スプライス閾値 (splice_threshold) | 1 〜 180° | 45 | パスを結合する角度の閾値 |
| パスモード (path_mode) | spline / polygon / none | spline | パスの描画方式。splineは曲線、polygonは直線、noneは生の点列 |

#### プレビュー操作

| 操作 | 効果 |
|------|------|
| マウスホイール | ズームイン / ズームアウト |
| ドラッグ | パン（画像の移動） |
| ダブルクリック | ズームリセット |

変換前（元画像）と変換後（SVG）のプレビューは同期して動く。

## 技術仕様

| 項目 | 内容 |
|------|------|
| 言語 | Python 3.12 |
| フレームワーク | Flask |

| メソッド | パス | 説明 |
|---------|------|------|

```
vtracer       # ベクター化（Rust実装）

```

---

## 注意事項

- **Python 3.12 必須**: vtracer は Python 3.11 以前で SIGSEGV が発生する場合がある
- **初回の背景除去は遅い**: rembg のAIモデル（数百MB）がダウンロードされるため
- **ベクター化の解像度制限**: 入力画像は長辺 512px に自動リサイズされる（メモリ節約のため）
- **処理時間**: ベクター化・背景除去は画像サイズや内容によっては数十秒かかる場合がある
